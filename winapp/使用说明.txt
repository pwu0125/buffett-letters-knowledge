巴菲特投资智慧 · Windows 版使用说明（v@VERSION@）
================================================

一、安装
  1. 双击「巴菲特投资智慧-v@VERSION@-Setup.exe」；
  2. 按提示安装（默认安装到 用户目录\AppData\Local\巴菲特投资智慧，
     无需管理员权限）；
  3. 安装完成页勾选「立即启动」即可开始使用。

  ※ SmartScreen 提示：安装包未做数字签名，首次运行可能出现蓝色提示，
    点击「更多信息」→「仍要运行」即可（与 Mac 版 Gatekeeper 处理方式同理）。

二、启动与使用
  - 开始菜单「巴菲特投资智慧」文件夹 →「巴菲特投资智慧」，或桌面快捷方式；
  - 应用自动静默启动内置的本地服务（http://127.0.0.1:8666，端口被占用时
    自动回退至 8667–8685）并打开 Edge 应用模式窗口（无地址栏，类原生窗口）；
    若系统没有 Edge，则改用默认浏览器打开；
  - 再次双击启动会复用已在运行的服务，不会重复启动；
  - 启动方式三级兜底：隐藏启动 → 可见最小化控制台 → 资源管理器方式启动。
    若安全软件拦截「隐藏启动」，任务栏会出现一个最小化的服务窗口，
    属正常现象，请勿关闭（关闭即停止服务）；
  - 关闭窗口后服务仍在后台运行：需要时双击「停止服务」结束它
    （卸载时也会自动停止）；
  - 离线模式兜底：若本地服务未能启动（例如安全软件拦截了内置 python），
    启动器会自动改用「离线模式」直接打开内置页面——阅读、搜索、划线、
    笔记功能全部正常，笔记/收藏保存在浏览器本地；此时任务栏不会有服务窗口。
    如需完整功能（数据文件持久化），把安装目录加入杀毒软件信任区后重试；
  - 启动器/停止服务为编译好的 exe 程序（非脚本），一般不会被安全软件误报；
    个别杀毒软件若对安装包内文件提示「脚本木马 / 启发式报毒」，
    属于误报（可先用记事本确认安装目录文件均为正常程序文件），
    将安装目录 %LOCALAPPDATA%\巴菲特投资智慧 加入信任区即可。

三、系统要求
  - 64 位 Windows 10 / 11；
  - 无需安装 Python —— 应用自带嵌入式 Python 运行时（python\ 文件夹）；
  - 完全离线可用：188 篇文章 / 分类索引 / 巴菲特与芒格人格对话全部内嵌。

四、LLM 密钥与联网检索（可选）
  - 应用内：页面右上角 ⚙ 设置 → 填写 API Key（仅存本机浏览器 localStorage）；
  - 或启动前设置环境变量 DEEPSEEK_API_KEY=sk-xxx；
  - 问答 AI 会先检索全部 188 篇文章、分类索引与权威收益数据（本地完成），
    再按「结论—证据链—口径与局限—可操作建议」作答，答复末尾附研究过程；
  - 如需核实语料之外的事实，可启用联网检索：在「设置」中选择提供方
    （博查 Bocha / Tavily）并填写搜索 API Key，或设置环境变量
    BOCHA_API_KEY / TAVILY_API_KEY；联网检索需以服务模式运行（默认如此）；
  - 默认模型 deepseek-v4-flash；环境变量密钥只进入服务内存，手填密钥仅存本机浏览器 localStorage。

五、数据与记忆材料
  - 笔记 / 高亮 / 收藏 / 已读 / AI 对话实时保存到：
      %APPDATA%\巴菲特投资智慧\state.json
  - 该目录属于本机用户数据；卸载时默认保留，勾选「同时删除笔记数据」才删除。

六、卸载
  - 开始菜单「巴菲特投资智慧」→「卸载巴菲特投资智慧」，或
  - 设置 → 应用 → 应用和功能 → 巴菲特投资智慧 → 卸载；
  - 卸载会停止本地服务，并清理文件、快捷方式与卸载注册表项；
  - 笔记数据默认保留（见第五节）。

七、故障排查
  - 启动后无窗口：首次启动约需 1-2 秒，请稍候；仍失败请双击「停止服务」后重试；
  - 启动报「本地服务启动失败」：弹窗会给出错误码与 python 自检结果——
    ① 若提示缺少文件：安装被安全软件拦截，请重新下载安装包重装（可暂时退出杀毒软件）；
    ② 若提示 python 无输出/拒绝访问：把安装目录加入杀毒软件信任区后重试；
    ③ 也可按弹窗提示，在「命令提示符」中手动运行那条命令，把完整报错发给我们；
  - 安装时报「无法打开要写入的文件」：说明有程序正在占用安装目录的文件（多为
    旧版服务仍在运行，或杀毒软件正在扫描/拦截）。处理：
    ① 关闭应用窗口，任务管理器结束所有 python.exe 进程；
    ② 暂时退出/暂停杀毒软件实时防护（360、火绒、Defender 等），
       或把安装目录 %LOCALAPPDATA%\巴菲特投资智慧 加入信任区；
    ③ 删除 %LOCALAPPDATA%\巴菲特投资智慧 整个文件夹后重新安装。
    新版安装器会自动停止旧版服务，此问题通常不会再出现；
  - 端口占用：8666 被其他程序占用时服务自动使用 8667–8685，无需手动处理；
  - 页面打不开：确认服务在运行（见第二节），或「停止服务」后重新启动；
  - 升级重装：直接运行新版 Setup.exe 覆盖安装即可，数据不受影响。

八、与 Mac 版的差异
  - 窗口：Mac 为原生窗口（Swift + WKWebView），Windows 为 Edge 应用模式窗口
    （外观与行为接近原生，能力来自系统预装的 Edge）；
  - 停止服务：Mac 关闭窗口即自动停止，Windows 需「停止服务」或卸载时自动停止。
